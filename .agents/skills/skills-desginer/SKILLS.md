# Habilidad de Revisión de Código (Code Review)

Al revisar código, sigue estos pasos:

## Lista de Verificación de Revisión

1. **Corrección Funcional:** Verificar que el código cumpla con las especificaciones y requisitos.
2. **Casos Límite (Edge Cases):** Asegurar que las condiciones de error y los límites de datos estén debidamente gestionados.
3. **Estilo y Convenciones:** Seguir las pautas de nomenclatura y patrones arquitectónicos del proyecto.
4. **Rendimiento:** Identificar posibles cuellos de botella, fugas de recursos o ineficiencias computacionales.
